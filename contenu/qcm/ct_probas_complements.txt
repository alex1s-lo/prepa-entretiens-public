=== ct-p-piece-equitable
+ Lancer deux fois : PF donne « pile », FP « face », PP ou FF : recommencer ; $\frac{1}{p(1-p)}$ lancers en moyenne

- Lancer une fois et inverser le résultat une fois sur deux

- Prendre la majorité sur trois lancers
  Le biais est réduit mais pas supprimé.
- C'est impossible sans connaître $p$

=== ct-partage-secret
+ Polynôme aléatoire de degré 2 de terme constant $s$, une valeur $P(i)$ par personne (schéma de Shamir)

- Couper le code en 5 morceaux
  Deux personnes apprennent des morceaux du code, et il en faut 5 pour le reconstituer.
- Donner à chacun le code chiffré avec la même clé
  Une seule personne avec la clé suffirait.
- Donner le code à 3 personnes seulement
  Le seuil doit valoir pour **n'importe quelles** 3 personnes.
